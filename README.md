# twinkly-f1

LEGO Technic MCL39 + Twinkly Squares wall display: mockup, video preview, and
hardware-push pipeline for a top-down satellite-imagery F1 lap visualization.

A wall-mounted LEGO F1 car sits inside a frame of Twinkly Squares LED tiles that
display top-down satellite imagery of a Monaco lap, scrolling and rotating
beneath the (visually fixed) car to create the illusion it is driving the
circuit.

## Circuit data pipeline

The display is driven by two inputs derived from satellite imagery, plus an
optimal trajectory computed by [`fastest-lap`](submodules/fastest-lap):

1. **Satellite mosaic** — a geo-registered image of the Monaco circuit,
   generated by [`racetrack-mosaic`](submodules/racetrack-mosaic). It is both
   the display source and the backdrop for tracing track limits.
2. **Track-limit KMLs** — hand-traced left/right circuit edges that
   `fastest-lap` needs to compute the optimal lap. See
   **[racetrack-mosaic: Tracing track limits for a lap optimizer](submodules/racetrack-mosaic/README.md#tracing-track-limits-for-a-lap-optimizer)**
   for the full workflow (build a backdrop → trace in Google Earth Pro → export
   `monaco_left.kml` / `monaco_right.kml`).
3. **Optimal trajectory** — `fastest-lap` runs in its Docker container against
   the traced circuit and emits the minimum-lap-time line, which
   `twinkly-mockup import-lap` converts into the renderer's trajectory CSV.
